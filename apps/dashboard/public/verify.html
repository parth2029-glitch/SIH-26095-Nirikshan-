Verify an inspection cycle

Every cycle publishes a commitment before its inspectors are drawn, and its random seed after the cycle closes. This page fetches that public record and re-runs the assignment engine in your browser. The server is not asked whether it cheated — the arithmetic is done here, on your machine, from source you can read.

Engine source: /core/assign.js — the same file the server ran. Public record: /api/cycles/<id>/verify.
